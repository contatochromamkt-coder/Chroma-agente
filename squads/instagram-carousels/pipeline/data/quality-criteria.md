# Quality Criteria — Carrossel Chroma

Compilado das seções "Quality Criteria" de `instagram-feed.md`, `instagram-reels.md`, `instagram-stories.md` e da metodologia de `review.md`. Vera Veredito usa este documento como rubrica única para avaliar as 3 peças de cada run.

## Carrossel de Feed (Carlos Carrossel)

- [ ] Formato do carrossel está explicitamente escolhido e segue o fluxo de slides correspondente (`instagram-feed.md`)
- [ ] Slide de capa tem título ousado e provocativo (máx. 20 palavras) que interrompe o scroll
- [ ] Cada slide usa hierarquia de duas camadas: headline em negrito + texto de apoio menor
- [ ] Cada slide tem no mínimo 40 palavras (headline + texto de apoio combinados), salvo pedido explícito de slides mais curtos
- [ ] Cada slide fica dentro de 80 palavras (headline + texto de apoio combinados)
- [ ] Cores de fundo alternam entre slides (claro, escuro, destaque) para ritmo visual
- [ ] Frases-chave destacadas em cor de destaque dentro das headlines
- [ ] Cada slide avança a narrativa — sem preenchimento ou repetição entre slides
- [ ] Primeiros 125 caracteres da legenda funcionam como hook independente
- [ ] Legenda termina com pergunta provocativa em aberto ou CTA claro
- [ ] Hashtags entre 5-15, com mix de nicho e amplas
- [ ] Slide final inclui CTA específico e acionável (não "me segue" genérico)

## Stories (Sofia Stories)

- [ ] Sequência tem entre 3-7 frames
- [ ] Frame de abertura chama atenção em até 2 segundos com hook visual ou textual
- [ ] Textos sobrepostos têm no máximo 2-3 linhas por frame, fonte grande e legível
- [ ] Pelo menos um frame inclui elemento interativo (enquete, quiz, pergunta ou slider)
- [ ] Prompts interativos são específicos e concretos, não vagos
- [ ] Tom é casual e conversacional, condizente com a natureza efêmera do formato
- [ ] Sequência segue arco narrativo (abertura, contexto, interação, fechamento)
- [ ] Conteúdo é nativamente vertical (9:16)

## Reel (Rafael Reels)

- [ ] Hook entrega gap de curiosidade ou promessa de valor claros nos primeiros 2 segundos
- [ ] Duração total entre 15-30 segundos para taxa de conclusão ideal
- [ ] Roteiro inclui direção de legendas/subtítulos embutidos
- [ ] Variedade visual presente — cortes ou mudanças de ângulo a cada 3-5 segundos
- [ ] Final desenhado para potencial de loop (conexão visual ou narrativa com o início)
- [ ] CTA é específico e acionável, não genérico
- [ ] Primeiros 125 caracteres da legenda funcionam como hook independente
- [ ] Direção de áudio especificada (som em alta ou áudio original)
- [ ] Conteúdo entrega o que o hook prometeu (sem isca-e-troca)

## Metodologia de revisão (Vera Veredito)

- **Escala**: cada critério recebe nota de 1-10 com justificativa escrita.
- **Aprovação**: nota geral >= 7/10 E nenhum critério individual abaixo de 4/10.
- **Aprovação condicional**: nota geral >= 7/10 mas um ou mais critérios não-críticos entre 4-6/10 — aprova com revisões menores obrigatórias listadas.
- **Rejeição**: nota geral < 7/10 OU qualquer critério abaixo de 4/10 (gatilho de rejeição automática, independente da média).
- **Escalada**: após 3 ciclos de revisão com os mesmos problemas, escalar para decisão do usuário.
- Toda rejeição deve incluir correção específica (o quê está errado, onde está, como corrigir).
- Todo feedback positivo deve indicar especificamente o que funcionou bem (mínimo 1 "Strength:" mesmo em rejeições).

## Critério de coerência entre peças

- [ ] As 3 peças (carrossel, stories, reel) usam o mesmo ângulo aprovado pelo usuário no checkpoint 3
- [ ] O tom de voz é consistente entre as 3 peças (mesma opção escolhida em `tone-of-voice.md`)
- [ ] Nenhuma peça contradiz outra em dados, números ou afirmações
